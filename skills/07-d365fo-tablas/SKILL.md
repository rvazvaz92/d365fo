# Tablas de D365FO

## Objetivo

Diseñar estructuras de datos coherentes con el modelo de datos y las convenciones de D365FO.

## Actividades

- Evaluar si se requiere una tabla nueva o una extensión de tabla estándar.
- Definir campos, tipos, propiedades, claves e índices necesarios.
- Diseñar relaciones y validar su cardinalidad y campos relacionados.
- Considerar integridad, eliminación, actualización y compatibilidad de datos.

## Resultado esperado

Una propuesta de tabla o extensión con campos, relaciones e índices justificados y sus impactos.
