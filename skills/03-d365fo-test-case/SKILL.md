# Casos de prueba

## Objetivo

Evaluar la calidad y cobertura funcional de los casos de prueba.

## Actividades

- Comprobar precondiciones, datos, pasos y resultado esperado.
- Validar que el flujo sea reproducible y que cada resultado sea observable.
- Revisar escenarios positivos, negativos, límites y permisos cuando correspondan.
- Detectar pasos ambiguos, datos faltantes y resultados que no se puedan verificar.

## Resultado esperado

Una revisión por caso con defectos, cobertura faltante y ajustes propuestos.
