# Etiquetas de D365FO

## Objetivo

Mantener textos de interfaz localizables y consistentes mediante etiquetas.

## Actividades

- Identificar textos visibles que deban ser etiquetas y no literales.
- Proponer etiquetas únicas, descriptivas y ubicadas en el archivo adecuado.
- Asignarlas a propiedades y elementos de datos o interfaz pertinentes.
- Revisar consistencia terminológica y contexto para traducción.

## Resultado esperado

Una lista de etiquetas con texto, contexto y objetos donde se deben asignar.
